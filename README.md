# Portfólio — Yara Firmino Camargo

Site estático (HTML, CSS e JavaScript puros), sem build e sem servidor:
basta servir a pasta.

- `index.html` — a página inteira; os cases abrem em pop-up na própria página
- `css/estilo.css` — o estilo base; `css/estilo-roxo.css` importa o base e define a paleta
- `js/movimento.js` — capa presa ao scroll, filtros, galerias, pop-ups
- `imagens/` — capas dos cases, galerias, vídeos e certificados
